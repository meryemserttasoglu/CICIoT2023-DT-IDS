# CICIoT2023 — Hybrid Digital Twin-Based Intrusion Detection System (DT-IDS)

A hybrid **Digital Twin (DT)-based Intrusion Detection System (IDS)** and
**Root Cause Analysis (RCA)** pipeline developed on the **CICIoT2023** dataset.
The framework combines supervised and unsupervised learning techniques,
including a Random Forest baseline, an Autoencoder trained on benign traffic
as the Digital Twin, a Conv1D-LSTM temporal model, and a late-fusion hybrid
architecture.

## Pipeline Stages

| Stage | Script | Description |
|-------|--------|-------------|
| 1 | `01_data_analysis.py` | Data exploration and analysis |
| 2 | `02_preprocessing.py` | Data preprocessing (scaling, encoding, train/test split) |
| 3 | `03_baseline_rf.py` | Baseline model — Random Forest |
| 4 | `04_autoencoder.py` | Autoencoder (Digital Twin) |
| 5 | `05_anomaly_detection.py` | Anomaly detection |
| 6 | `06_convlstm.py` | Conv1D-LSTM temporal model |
| 7 | `07_rca.py` | Root Cause Analysis (SHAP + reconstruction error) |
| 8 | `08_hybrid_model.py` / `08b_hybrid_rf.py` | Hybrid late-fusion model |
| 9 | `09_results_analysis.py` | Results analysis and comparison |
| 10 | `10_dashboard.py` | Streamlit dashboard |

Additional utilities:

- `config.py`
- `utils.py`
- `run_pipeline.py`
- `09_loao.py` (Leave-One-Attack-Out evaluation)
- `make_*_docx.py` (automatic report generation)

## Installation

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

---

## Dataset

This repository **does not include the raw dataset or trained models**, as
their sizes exceed GitHub's storage limits.

The **CICIoT2023** dataset is publicly available from the
**Canadian Institute for Cybersecurity (CIC)**:

https://www.unb.ca/cic/datasets/iotdataset-2023.html

After downloading the CSV partitions, place them under:

```
data/raw/
```

Then execute the pipeline. The processed dataset (`data/processed/`) and trained
models (`models/`) will be generated automatically.

---

## Running the Pipeline

```bash
python run_pipeline.py            # Run all stages (1→9)
python run_pipeline.py --stage 3  # Run only Stage 3
python run_pipeline.py --from 4   # Run from Stage 4 onward
streamlit run 10_dashboard.py     # Launch the dashboard
```

## Performance Summary

| Model | F1-Score |
|-------|----------|
| Random Forest (Baseline) | **0.9929** |
| Autoencoder (Digital Twin) | **0.9857** (ROC-AUC: **0.9884**) |
| Conv1D-LSTM | **0.6738** |
| Hybrid Late-Fusion Model | **0.6304** |

A detailed discussion of the experimental findings can be found in:

- `results/09_discussion.txt`
- `results/figures/`
